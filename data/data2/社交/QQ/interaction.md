# 5个页面

## 消息

1.底部导航栏可以跳转到频道、联系人和动态

## 频道

1.底部导航栏可以跳转到消息、联系人和动态

## 联系人

1.底部导航栏可以跳转到频道、消息和动态

## 动态

1.底部导航栏可以跳转到频道、联系人和消息

2.点击右上角可以进入设置页面

| 入口页面 | 跳转/进入页面      | 触发交互方式   | 跳转数量 |
| -------- | ------------------ | -------------- | -------- |
| 消息     | 频道、联系人、动态 | 底部导航栏跳转 | 3        |
| 频道     | 消息、联系人、动态 | 底部导航栏跳转 | 3        |
| 联系人   | 频道、消息、动态   | 底部导航栏跳转 | 3        |
| 动态     | 频道、联系人、消息 | 底部导航栏跳转 | 3        |
| 动态     | 设置页面           | 点击右上角图标 | 1        |
